# Research Index - Survey / Ophélia

This repository is treated as a legacy platform repository for Ophélia and civic survey tooling. The
corpus index favors human-facing architecture, API, product and deployment documents. Generated
build copies, runtime public document dumps, prompts, package internals and script notes are
excluded through `.cogentiaignore` until they receive a more precise curation policy.
