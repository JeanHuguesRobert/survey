# Kudocracy – Public Roadmap

## Phase 1 – Core (0–3 months)

- Proposal creation
- Voting
- Vote delegation (liquid democracy)
- Basic moderation
- Audit log

## Phase 2 – Transparency (3–6 months)

- Public vote traceability
- Exportable results (CSV / PDF)
- Public statistics dashboard

## Phase 3 – Interoperability (6–12 months)

- API for external platforms
- Import/export between towns
- Federation-ready architecture
